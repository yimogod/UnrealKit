# 测试与质量约定

当前状态：79 个测试，全部通过，0 警告 0 错误（`dotnet test UnrealKit/UnrealKit.sln`）。

## 测试框架与布局

- xUnit 2.9.2 + `Microsoft.NET.Test.Sdk` 17.12.0，coverlet 收集覆盖率。
- `UnrealKit.Tests` 目标框架为 `net9.0-windows`，因为它同时测试 `UnrealKit.Desktop` 的 ViewModel。
- 测试数据位于 `UnrealKit.Tests/TestData/<域>/`，通过 `.csproj` 的 `CopyToOutputDirectory="PreserveNewest"` 复制到输出目录。新增样本类型时必须补一条对应的 `None Update` 规则，否则测试在 CI 上找不到文件。

现有测试数据目录：

```text
TestData/
├─ MemInfo/       *.txt        完整、重复区段、明细异常、缺失总计、OEM 变体、截断
├─ MemReport/     *.memreport  完整明细
└─ StaticCamera/  *.log
```

## 金样测试

为 Android meminfo、UE memreport、静态相机日志解析器提供脱敏样本和金样测试。

- 样本必须脱敏：不含真实包名、设备序列号、内部工程名或人员信息。
- 新增解析规则时，至少添加一个成功样本和一个格式异常样本，异常样本断言具体诊断码而非「有诊断」。
- 断言具体数值和诊断码，不只断言「解析未抛异常」。

## 覆盖要求

| 层 | 要求 |
| --- | --- |
| Core 服务 | 单元测试覆盖成功路径与失败路径 |
| 解析器 | 金样测试 + 格式异常测试 |
| 导出服务 | 每种格式（CSV/TSV/XLSX）各自验证 |
| 端到端 | 解析 → 导出全链路（见 `EndToEndExportTests`） |
| ShellViewModel | 业务流程在无 UI 环境下可测（见 `DesktopShellViewModelTests`） |
| ProcessRunner | 退出码、超时、取消、流式输出 |

GUI code-behind 不承载业务流程，业务逻辑保持在可测试的 ViewModel/Core 中。

## 验证流程

- 修改 Core 后优先运行相关单元测试，再跑全量。
- 修改 CLI 后验证成功、参数错误和外部命令失败三条路径。
- 提交前构建必须无警告：`TreatWarningsAsErrors=true`，警告会直接中断构建。
- 涉及设备的功能无法在单元测试中完整覆盖时，用 `IProcessRunner` 的测试替身模拟 adb 输出，不要跳过测试。

## 边界

- 不修改或「修复」与当前任务无关的测试失败；在交付说明中单独指出。
- 不通过放宽断言或删除测试让构建变绿。
- 不为提升覆盖率数字添加无断言的测试。
