# 设备操作与文件安全

## 外部进程调用

所有外部命令统一经 `UnrealKit.Core.Processes.ProcessRunner` 执行。

- 使用 `ProcessStartInfo.ArgumentList` 等参数化方式传参；禁止通过未经处理的字符串拼接构造 shell 命令。设备序列号、包名、远端路径均可能包含空格或特殊字符。
- 每次执行都要捕获退出码、标准输出和标准错误，并支持超时与取消。
- 取消时终止整个进程树，避免 `adb pull` 等子进程残留。
- 逐行流式输出通过 `IProgress<ProcessOutput>` 上报，供 GUI 实时显示与 CLI 日志使用。

## ADB 路径解析

`AdbPathResolver` 按固定顺序解析 adb，并记录每一步尝试：

1. `Explicit` — CLI `--adb-path` 或 GUI 显式设置
2. `ProjectSettings` — `ProjectSettings.AdbPath`
3. `EnvironmentVariable` — 依次 `ADB_PATH`、`ANDROID_SDK_ROOT`、`ANDROID_HOME`
   （`ADB_PATH` 视为可执行文件路径；后两者拼接 `platform-tools/adb[.exe]`）
4. `Path` — 遍历 `PATH` 各目录

每次尝试产出 `AdbPathAttempt(Source, Description, CandidatePath, Status)`，`Status` 为 `NotConfigured` / `NotFound` / `Resolved`。解析失败时抛出 `AdbPathResolutionException`，其中携带完整 `AdbPathResolution`，供 UI 展示「查了哪些位置、为什么没找到」。

诊断能力依赖这份尝试清单，不要为了简化而丢弃它。多个 adb 版本共存时，用工程配置消除歧义。

## 设备选择

- 支持按 ADB 序列号明确选择设备；所有设备相关命令必须携带选择结果。
- GUI 刷新设备后不自动选中唯一设备，由用户显式选择。
- CLI `--device auto` 仅在恰好一台设备在线时成立，否则报错。
- 设备状态（`device` / `unauthorized` / `offline` 等）必须对用户可见，不静默把非就绪设备当作可用。

## 文件操作安全

- GUI 中执行会覆盖、删除或清空目录的操作前，必须明确显示目标路径并要求确认。
- 默认优先使用带时间戳的新输出目录，避免无提示清空历史采集数据。
- 写入 `Content/` 前确认目标 Capture 目录不存在或为空；不要在已有 Capture 上追加不同来源的文件。
- 清理 `Saved/`、`Intermediate/` 的操作不得触及 `Content/`。
- 删除设备端文件（如 `commandline delete`）前展示远端完整路径。

## 敏感信息

- 不在日志、Manifest 或导出结果中写入密钥、令牌或凭据。
- 设备序列号会进入 `CaptureManifest.json`；如需分享归档，由用户决定是否脱敏，工具不擅自改写原件。
