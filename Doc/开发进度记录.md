### M1：`.ukit` 工程与配置

- Core 中已实现工程模型与服务：
  - `Projects/ProjectModels.cs`
  - `Projects/IniDocument.cs`
  - `Projects/ProjectService.cs`
- 支持创建、打开、校验 `.ukit` 工程。
- 创建工程会生成：
  - `<Name>.ukit`（UTF-8 INI，格式版本为 1）
  - `Config/DefaultGame.ini`
  - `Content/`、`Saved/`、`Intermediate/`
- 非空目标目录会被拒绝，避免静默覆盖。
- 校验会报告工程格式版本、必需目录、工程名称和缺失配置的结构化诊断。
- CLI 已支持：
  - `project create <directory> --name <name>`
  - `project info <project.ukit> [--format json]`
  - `project validate <project.ukit>`
- WPF 已建立无业务逻辑的导航壳：工程、设备、启动参数、采集、解析、结果、日志与设置。

### M2：已完成部分

#### 安全进程执行器

- 文件：
  - `UnrealKit.Core/Processes/ProcessExecutionModels.cs`
  - `UnrealKit.Core/Processes/IProcessRunner.cs`
  - `UnrealKit.Core/Processes/ProcessRunner.cs`
- `ProcessRunner` 使用 `ProcessStartInfo.ArgumentList`，不通过拼接 shell 命令传递参数。
- 可记录/返回：退出码、stdout、stderr、开始/结束时间和耗时。
- 支持取消令牌、超时、超时/取消时终止整个进程树、进度与结构化日志。

#### ADB 设备与命令服务

- 文件：
  - `UnrealKit.Core/Adb/AdbModels.cs`
  - `UnrealKit.Core/Adb/AdbDeviceParser.cs`
  - `UnrealKit.Core/Adb/IAdbService.cs`
  - `UnrealKit.Core/Adb/AdbService.cs`
- `adb devices -l` 解析支持制表符与空格分隔，识别：序列号、`device/offline/unauthorized`、产品、型号、设备名及 USB/Wi-Fi 类型。
- 已实现：`version`、`devices -l`、server 启停、Wi-Fi connect/disconnect、`tcpip`。
- 已提供后续采集可复用的方法：启动应用、push、pull、远端删除、`dumpsys meminfo`。
- 任何设备相关命令都要求显式序列号，并统一传入 `-s <serial>`。
- 本地路径、Android 包名、远端 Unix 绝对路径均做基础校验。
- ADB 非零退出码抛出 `AdbCommandException`，保留退出码、stdout 和 stderr。

#### CLI ADB 基础命令

- `UnrealKit.Cli/Program.cs` 已以 UTF-8 重写，修复了移动目录后出现的中文乱码。
- 已支持：
  - `adb version [--adb-path <path>]`
  - `adb devices [--adb-path <path>]`
  - `adb connect <host:port> [--adb-path <path>]`
  - `adb disconnect <host:port> [--adb-path <path>]`
- ADB 不存在时 CLI 会输出可读错误并返回退出码 `1`。

#### 启动参数服务与 CLI

- 新增 `UnrealKit.Core/Launch/`：`LaunchParameterService` 负责组合项目预设和自定义参数、创建临时 UTF-8 `uecommandline.txt`、推送至设备、删除设备文件以及启动已配置应用。
- `ProjectSettings` 新增 `DeviceGameRootTemplate`；创建工程时的 `Config/DefaultGame.ini` 会保存 LLM、LLM CSV、OpenGL、Vulkan、Trace、No Update 预设名称。
- LLM、LLM CSV、OpenGL、Vulkan 保留旧工具中已知参数。旧代码未提供 Trace 与 No Update 的精确参数文本，因此这些预设默认留空，要求使用者在 `DefaultGame.ini` 中按项目旧规则显式填写，避免猜测参数。
- CLI 新增显式设备与工程参数命令：
  - `app start --project <project.ukit> --device <serial>`
  - `commandline push --project <project.ukit> --device <serial> [--preset <name>] [--custom <arguments>]`
  - `commandline delete --project <project.ukit> --device <serial>`
- 推送后的临时文件会在成功、失败或取消后清理；非可叠加预设（例如 OpenGL/Vulkan/Trace）不可与其他预设混用。
